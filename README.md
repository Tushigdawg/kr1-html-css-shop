# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

- `index.html` — главная страница;
- `css/style.css` — файл стилей;
- `images/` — папка для изображений;
- `.gitignore` — список файлов, исключённых из Git;

## Контрольная работа №1: доработки

- `product.html` — подробная карточка товара: параметры (цвет, количество), якорная навигация, описание, доставка и оплата;
- таблица характеристик с группами строк и таблица сравнения товаров (`data-table`, `caption`, `scope`, прокрутка внутри `table-scroll`);
- модальное окно: кнопка-крестик, закрытие по фону и Esc, блокировка прокрутки страницы, возврат фокуса на кнопку, название выбранного товара;
- доступность формы: ссылка «Перейти к основному содержимому», сообщения об ошибках у каждого поля (`aria-describedby`, `aria-invalid`), список ошибок со ссылками на поля, `fieldset`/`legend` для выбора способа связи, `autocomplete`, `role="status"` для сообщения об успехе, `aria-current` в навигации, `prefers-reduced-motion`.

Страница `product.html` показывает товар по номеру из адреса, например `product.html?id=8`; данные товаров лежат в `js/main.js`.
