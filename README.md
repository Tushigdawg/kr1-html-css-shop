## Краткое описание проекта

TechStore — многостраничный HTML/CSS-сайт интернет-магазина электроники. Сайт состоит из пяти связанных страниц с единой навигацией, карточками товаров, таблицей характеристик, формой заявки и модальным окном. Проект выполнен без CSS-фреймворков и без JavaScript-интерактивности (JavaScript используется только для открытия и закрытия модального окна).

## Описание обязательных страниц

| Страница | Содержание |
|----------|------------|
| `index.html` | Главная страница: hero-блок, преимущества, популярные товары, якорные ссылки |
| `catalog.html` | Каталог: карточки товаров, категории, статический блок фильтров |
| `product.html` | Карточка товара: изображение, описание, цена, таблица характеристик, кнопка заказа, модальное окно `<dialog>` |
| `order.html` | Форма заявки: имя, e-mail, телефон, товар, комментарий, согласие на обработку данных |
| `contacts.html` | Контактная информация и ссылка на форму заявки |

Общие элементы всех страниц: уникальный `title`, единая навигация, подключение `css/style.css`, семантическая структура (`header`, `nav`, `main`, `footer`).

## Реализованные требования

- Семантическая разметка: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`
- Единая навигация и якорные ссылки
- Карточки товаров с бейджем «Sale» и БЭМ-модификатором `product-card--discount`
- Таблица с `caption`, `thead`, `tbody`, `th`, `td`
- Форма: `label`, `for`/`id`, `name`, `required`, `type="email"`
- Модальное окно на базе `<dialog>`
- CSS-переменные в `:root`
- Состояния `:hover`, `:focus-visible`, `:disabled`
- Flexbox (шапка, меню, кнопки) и CSS Grid (сетка товаров, раскладка каталога)
- БЭМ-именование классов
- Позиционирование: `relative`, `absolute`, `sticky`, `fixed`, `z-index`

## Самостоятельные доработки

- Собственная визуальная концепция: единая цветовая палитра и типографика
- Статический блок фильтров в каталоге (`aside`)
- Бейджи и модификаторы карточек товаров
- Блок преимуществ на главной странице
- Быстрый заказ через модальное окно `<dialog>`
- Улучшенная доступность: видимый фокус, подписи полей, контрастные цвета
